# 📡 Telegraph

Translate text to Morse code and back, hear it played, and tap your own messages on a telegraph key.

**▶ Use it here: [https://drew-traldi.github.io/telegraph-me-the-code/](https://drew-traldi.github.io/telegraph-me-the-code/)**

- Free, no sign-up, no ads
- Runs entirely in your browser. Nothing you enter is sent to a server.
- Works on desktop and mobile

## Run it locally

It's a single HTML file. Download `index.html` and open it in any modern browser.
